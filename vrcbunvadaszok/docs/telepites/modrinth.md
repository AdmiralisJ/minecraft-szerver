# Modrinth App

## Letöltés és telepítés

[:material-download: Modrinth App letöltése](https://modrinth.com/app){ .md-button .md-button--primary }

1. Nyisd meg a letöltött telepítőt
2. Kattints végig a **Next** gombokra
3. Indítsd el a Modrinth App-ot

---

## Beállítás

### Java beállítása

A Modrinth App általában **automatikusan megtalálja** a Java 21-et.
Ha mégsem, menj a beállításokba: **Settings → Java** és válaszd a Java 21-et.

![Modrinth Java beállítás gif](../assets/modrinth-java.gif)

---

## Modpack telepítése

### 1. Modpack letöltése

[:material-download: Modpack letöltése (.mrpack)](https://LINK_IDE){ .md-button }

### 2. Importálás

![Modrinth modpack import gif](../assets/modrinth-import.gif)

1. A főoldalon kattints a **+** gombra
2. Válaszd az **Import** opciót
3. Tallózd ki a letöltött `.mrpack` fájlt
4. Várd meg amíg települ

!!! warning "Első indítás"
    Az első indítás hosszabb ideig tarthat – türelem, letölti a modokat!
