# Prism Launcher

## Letöltés és telepítés

[:material-download: Prism Launcher letöltése](https://prismlauncher.org/download/){ .md-button .md-button--primary }

1. Nyisd meg a letöltött telepítőt
2. Kattints végig a **Next** gombokra
3. Indítsd el a Prism Launchert

---

## Beállítás

### Java beállítása

Az első indításkor a Prism megkérdezi, melyik Java verziót használja.
Válaszd a **Java 21**-et (amit korábban telepítettél).

![Prism Java beállítás gif](../assets/prism-java.gif)

!!! tip "Ha nem találja automatikusan"
    Kattints a **Browse** gombra és keresd meg manuálisan:
    `C:\Program Files\Eclipse Adoptium\jdk-21...\bin\javaw.exe`

---

## Modpack telepítése

A szerver saját modpackot használ, amit importálni kell.

### 1. Modpack letöltése

[:material-download: Modpack letöltése (.mrpack)](https://LINK_IDE){ .md-button }

### 2. Importálás

![Prism modpack import gif](../assets/prism-import.gif)

1. Jobb klikk az üres területre → **Add Instance**
2. Bal oldalt válaszd az **Import** opciót
3. Tallózd ki a letöltött `.mrpack` fájlt
4. Kattints az **OK** gombra és várd meg a letöltést

!!! warning "Első indítás"
    Az első indítás hosszabb ideig tarthat – türelem, letölti a modokat!
