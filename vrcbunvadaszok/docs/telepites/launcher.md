# Launcher választás

Két launchert ajánlunk – mindkettő ingyenes és remekül működik.
Olvasd el az összehasonlítást és válaszd a neked szimpatikusabbat.

---

## Összehasonlítás

| | Prism Launcher | Modrinth App |
|---|---|---|
| **Kezelőfelület** | Letisztult, haladóknak | Modern, egyszerű |
| **Modpack kezelés** | Manuális import + automatikus | Beépített böngésző |
| **Modrinth integráció** | Részleges | Teljes |
| **Testreszabhatóság** | Nagy | Közepes |
| **Ajánlott** | Ha szereted az irányítást | Ha gyors és egyszerű kell |

---

## Prism Launcher

**Miért jó?**

A Prism Launcher egy nyílt forráskódú, rendkívül testreszabható launcher.
Minden egyes példányhoz (instance) külön Java verziót, memóriát és beállítást adhatsz meg.
Ha szereted tudni, mi történik a háttérben, ez a te launchered.

- :white_check_mark: Teljes irányítás minden beállítás felett
- :white_check_mark: Több Minecraft példány egymás mellett gond nélkül
- :white_check_mark: Könnyen importálható `.mrpack` modpackok
- :white_check_mark: Nyílt forráskód, közösség által fejlesztett

[:octicons-arrow-right-24: Prism Launcher telepítése](prism.md){ .md-button .md-button--primary }

## Modrinth App

**Miért jó?**

A Modrinth App a Modrinth platform saját launchere – beépített modpack böngészővel
és automatikus frissítésekkel. Ha egyszerű, modern felületet szeretnél és nem akarsz
sokat konfigurálni, ez az ideális választás.

- :white_check_mark: Beépített modpack és mod böngésző
- :white_check_mark: Automatikus modpack frissítések
- :white_check_mark: Gyors telepítés, kevés kattintás
- :white_check_mark: Letisztult, modern megjelenés

[:octicons-arrow-right-24: Modrinth App telepítése](modrinth.md){ .md-button .md-button--primary }
