    Modrinth App¶

    Letöltés és telepítés¶

    Modrinth App letöltése

    1. Nyisd meg a letöltött telepítőt
    2. Kattints végig a Next gombokra
    3. Indítsd el a Modrinth App-ot

    Beállítás¶

    Java beállítása¶

    A Modrinth App általában automatikusan megtalálja a Java 21-et. Ha mégsem, menj a beállításokba: Settings → Java és válaszd a Java 21-et.

    Modpack telepítése¶

    1. Modpack letöltése¶

    Modpack letöltése (.mrpack)

    2. Importálás¶

    1. A főoldalon kattints a + gombra
    2. Válaszd az Import opciót
    3. Tallózd ki a letöltött .mrpack fájlt
    4. Várd meg amíg települ

    Első indítás

    Az első indítás hosszabb ideig tarthat – türelem, letölti a modokat!

    Kész!

    Ha elindult a játék, folytatás a csatlakozásnál.
